# 🚀 Experiencia y Proyectos

## 🦷 AlineaDent — Sistema inteligente de gestión dental
**Desarrollo Full-Stack e Inteligencia Artificial | Agosto 2025 – Actualidad**

Plataforma integral de gestión para un consultorio dental, que combina administración clínica, automatización conversacional mediante IA y análisis de datos operativos.

**Funcionalidades principales:**
- 📅 Gestión de pacientes, citas y tratamientos.
- 🤖 Chatbot conversacional con IA integrado mediante la API oficial de WhatsApp Business de Meta, con coexistencia con WhatsApp Business App.
- 📲 Automatización de aproximadamente el **72 % de los casos de agendamiento**, con derivación al personal cuando se requiere atención humana.
- 💬 Panel de monitoreo de conversaciones entre pacientes y el chatbot.
- 📊 Dashboards interactivos con indicadores operativos para apoyar la toma de decisiones.
- 🦷 Administración de fotografías clínicas para el seguimiento de tratamientos odontológicos, utilizando Cloudflare R2.
- 📱 Interfaz responsiva para computadoras, tabletas y dispositivos móviles.

**Stack tecnológico:**
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS.
- **Backend:** Python, FastAPI, APIs REST.
- **Datos:** PostgreSQL, Redis.
- **IA e integraciones:** OpenAI API, Meta WhatsApp Cloud API.
- **Infraestructura:** Railway, Vercel, Cloudflare R2.

## 🛠️ Nueva Ferretería Orión — Sistema integral de gestión comercial
**Desarrollo Full-Stack, Business Intelligence y Forecasting | Septiembre 2026 – Actualidad**

Sistema web de punto de venta, inventarios y facturación electrónica, desarrollado para digitalizar operaciones comerciales y facilitar la toma de decisiones basada en datos.

**Funcionalidades principales:**
- 🛒 Punto de venta (POS) optimizado para dispositivos móviles y computadoras.
- 📦 Administración de inventarios y catálogo de miles de productos, con búsqueda flexible por marcas, medidas y presentaciones.
- 🧾 Integración de facturación electrónica CFDI 4.0.
- 📊 Dashboards interactivos para visualizar ventas, inventarios y métricas comerciales.
- 📈 Modelos de forecasting para pronosticar demanda y apoyar decisiones de reabastecimiento y compras a proveedores.
- 💰 Registro de ventas, devoluciones y entradas de mercancía.
- 👥 Gestión de usuarios con funcionalidades diferenciadas para administradores y cajeros.
- 📱 Interfaz web responsiva para agilizar las operaciones desde teléfonos celulares.

**Stack tecnológico:**
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS.
- **Backend:** Python, FastAPI, APIs REST.
- **Base de datos:** PostgreSQL.
- **Análisis de datos:** Python, SQL, forecasting y visualización de indicadores.
- **Integraciones:** Servicios de facturación electrónica CFDI 4.0.
